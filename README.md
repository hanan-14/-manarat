# منارة الناشئة | Manarat Al-Nashia
مساعد آلي (AI) يجيب أسئلة الناشئة (9-15 سنة) عن الإسلام من مصادر معتمدة، بلغة السائل، مع ذكر المصدر.
المسار: الحوار المعرفي والإجابات الموثوقة.

## كيف يعمل
1. يكتب الطفل سؤاله بأي لغة.
2. Claude يبحث عبر واجهات **HadeethEnc** (الأحاديث الصحيحة) و**QuranEnc** (القرآن وترجماته)، وهما من مصادر الحزمة العلمية.
3. يصوغ جواباً بسيطاً من النص المسترجع فقط، ويذكر المصدر، ويفرّق بين النص والشرح.
4. المستويات (أ/ب/ج/د): الفتوى والحالات الشخصية (د) = إحالة للوالدين أو المعلم أو المختص. وعند غياب المرجع: امتناع.

## الخصوصية
لا حسابات ولا بريد ولا أسماء حقيقية. اسم مستعار اختياري، والنجوم تُحفظ في الجلسة فقط.

## الشفافية
الأداة مساعد آلي وليست شيخاً، وهذا مكتوب في الواجهة.

## التشغيل
pip install -r requirements.txt
ضع المفتاح في .streamlit/secrets.toml (انسخه من secrets.toml.example)
streamlit run app.py

لا يغني عن العلماء. 30 سؤالاً كحد أقصى للجلسة. النتائج تعتمد على ما تعيده الواجهات.
