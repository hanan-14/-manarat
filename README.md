# منارة الناشئة | Manarat Al-Nashia
مساعد آلي (AI) يجيب أسئلة الناشئة (9-15 سنة) عن الإسلام من مصادر معتمدة، بلغة السائل، مع ذكر المصدر والإجابات الموثوقة.
المسار: الحوار المعرفي والإجابات الموثوقة.

## كيف يعمل
1. يكتب الطفل سؤاله بأي لغة.
2. يعتمد نموذج Gemini على توجيهات صارمة تستمد المعلومات من واجهات المصادر والموسوعات المعتمدة (مثل HadeethEnc و QuranEnc).
3. يصوغ جواباً بسيطاً من النص المعتمد فقط، ويذكر المصدر، ويفرّق بين النص والشرح.
4. المستويات (أ/ب/ج/د): الفتوى والحالات الشخصية (د) = إحالة للوالدين أو المعلم أو المختص. وعند غياب المرجع: امتناع.

## الخصوصية
لا حسابات ولا بريد ولا أسماء حقيقية. اسم مستعار اختياري، والنجوم تُحفظ في الجلسة فقط.

## الشفافية
الأداة مساعد آلي وليست شيخاً، وهذا مكتوب في الواجهة.

## التشغيل
pip install -r requirements.txt
ضع مفتاح جيميني في .streamlit/secrets.toml تحت اسم GEMINI_API_KEY
streamlit run app.py

## الحدود
لا يغني عن العلماء. 30 سؤالاً كحد أقصى للجلسة لحماية رصيد الاستخدام المجاني. النتائج تعتمد على المصادر المعتمدة.
